# mindbox-test-k8s

Этот репозиторий содержит Kubernetes-манифест для развертывания приложения **mindbox-test** в мультизональном кластере.

## Описание решения

В манифест включены:
- **Deployment** — основная конфигурация приложения.
- **Horizontal Pod Autoscaler (HPA)** — автоматическое масштабирование по нагрузке.
- **CronJob** — ночное масштабирование для экономии ресурсов.

### Цели решения:
- **Максимальная отказоустойчивость**:  
  Используется `topologySpreadConstraints`, чтобы равномерно распределять поды по зонам.
- **Оптимизация ресурсов**:  
  Минимум реплик ночью, автоматическое масштабирование в течение дня.
- **Долгая инициализация**:  
  `startupProbe` учитывает, что приложение стартует 5–10 секунд.
- **Гарантированная готовность**:  
  `readinessProbe` проверяет, что под полностью готов к обработке запросов.
